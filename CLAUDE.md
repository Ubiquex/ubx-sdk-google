# CLAUDE.md — ubx-sdk-google

## What this is

Typed bindings for Google Cloud (`[dynamic_provider_groups.google_all]`,
Discovery-Doc-sourced via `ubx-provider-dynamic`), generated by `ubx sdk gen`
(`github.com/ubiquex/ubiquex`, the coordinating repo), for all three SDK
languages in one combined repo:

- `sdk/go/` — Go bindings, module `github.com/ubiquex/ubx-sdk-google/sdk/go`
  (a subdirectory Go module, tagged `sdk/go/vX.Y.Z`)
- `sdk/typescript/` — TypeScript bindings, published to JSR as `@ubx/sdk-google`
- `sdk/python/` — Python bindings, published to PyPI as `ubx-sdk-google`
  (imported as `ubx.google.*`, a real PEP 420 namespace package)

262 real Google Cloud products/versions behind one binding surface.
`VERSION` at repo root records the real, merged upstream spec this
generation was fetched from (sha256 + member count + date + source), the
provenance record for what's currently checked in, not a semantic version.

## Session protocol

1. Read `STATE.md` first — current state only, rewritten not appended.
2. `STATE.md` is rewritten, not appended, as the LAST act of every session.
   Anything that becomes history moves to `HISTORY.md`.
3. Only reference Linear issue IDs given in the handoff prompt; never infer
   one.

## Git rules (strict)

- PR-only. Never self-merge — push a branch, open a PR, wait for the founder.
- NO AI attribution anywhere in commits or PR bodies.

## Publishing discipline

- Three independent registries, three independent version numbers per
  language — never assume they agree. Verify each directly before trusting
  parity: Go module proxy (`gh api repos/Ubiquex/ubx-sdk-google/tags`),
  `jsr.io/@ubx/sdk-google`, `pypi.org/project/ubx-sdk-google`. A commit to
  this repo's own `main` is NOT the same as "published" for any of the three
  (`ubiquex`'s own CLAUDE.md rule 8, UBI-131).
- These bindings are generated, not hand-written — a real fix belongs in
  `ubiquex`'s own `sdk/codegen/` (or the upstream schema, if the bug is in
  what's being generated FROM, see `ubx-schema-google`), then regenerated
  here, never hand-patched in the generated output directly.
